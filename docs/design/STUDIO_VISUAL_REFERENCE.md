## Canonical visual direction

The Studio should feel like a real, premium creative environment rather than a generic AI/SaaS dashboard.

### Environment

- Professional recording-studio atmosphere.
- Deep black/dark surfaces.
- Warm gold/brass architectural accents.
- Subtle red Buddy accents where appropriate.
- Warm cinematic lighting.
- Layered depth and believable physical materials.
- Premium but functional.
- Music-production equipment and details used as visual inspiration.
- Avoid sterile white/blue “AI dashboard” aesthetics.

### Relationship to Buddy

Buddy is the Studio's intelligent creative companion, not a decorative mascot pasted onto an unrelated interface.

The UI and environments should visually connect Buddy's:

- Black/red palette
- Headphone/audio identity
- Red waveform motif
- Friendly futuristic character

with the Studio's:

- Dark professional recording-room aesthetic
- Warm gold/brass lighting
- Real-world music-production atmosphere

### Planned visual behavior

The Studio can eventually include coherent visual states such as:

- Day mode
- Night mode
- Working/processing state
- Listening state
- Generation state
- Success state
- Error/recovery state
- Buddy Off the Chain state
- Music-reactive effects
- Subtle edge/rim lighting

Effects should remain tasteful and functional rather than becoming visual noise.
