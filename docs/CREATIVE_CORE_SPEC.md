# Little Red's Big Studio — Creative Core

This document is the product contract for Buddy's invisible technical layer.

## User experience contract

The user states an outcome. Buddy chooses the workflow, model, provider and technical settings automatically. Provider changes, retries, queue handling, preprocessing, quality checks and recovery remain hidden unless the user explicitly asks for technical details.

## Creative continuity

Buddy maintains a persistent Creative Project Graph linking projects, assets, versions, characters, voices, lyrics, songs, artwork, videos, campaigns and decisions. Long-term memory stores preferences, lessons, failures, relationships and Creative DNA. Browser-local memory is a fallback; account-backed persistence is required for true cross-device/lifelong recall.

## Outcome engine

Every creation job follows:

1. Understand intent.
2. Inspect available capabilities.
3. Choose the best healthy route for the task.
4. Preserve originals.
5. Execute.
6. Validate the actual artifact.
7. Resume from the last successful stage after recoverable failures.
8. Try the next best route when necessary.
9. Compare viable results when useful.
10. Deliver only a usable result.

A request is not considered successful merely because a provider accepted it.

## Quality and recovery

The runtime should detect malformed, empty, silent, corrupted, incomplete or obviously unsuitable results. Known failures are remembered so the same route is not repeatedly selected. Temporary provider failures use cooldowns and automatic recovery. Jobs are resumable, cancellable and protected from accidental duplicates.

## Web intelligence

Buddy may search the live web when current information materially improves the task. Research is source-aware and should distinguish verified information from inference.

## Creative judgment

Buddy can propose a better approach, explain trade-offs when useful, generate alternatives, critique its own work, run creative A/B comparisons and use the user's Creative DNA to keep results consistent over time.

## Visual identity

Buddy remains visually consistent using the canonical character reference. The Studio uses the Little Red's Big Studio logo and premium animated visual language across the experience while respecting reduced-motion and accessibility settings.

## Free-tier export policy

Free-tier visual exports carry the official Studio logo watermark. Paid users may remove the watermark only after a trusted subscription/account entitlement is verified. Client-side local storage must never be treated as proof of payment.

## Privacy and portability

User-created originals remain distinct from generated derivatives. Creative memory should be exportable. User identity and memory are isolated by account when accounts are available. The browser must never receive secret provider credentials.

## Platform contract

Android-first, mobile-friendly, no computer required for ordinary use, no mandatory local installation for ordinary use, and free/open/public resources preferred whenever they can deliver the required quality and reliability.
